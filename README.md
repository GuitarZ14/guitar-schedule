# 吉他教学工作台

基于 [guitarz14/guitar-schedule](https://github.com/guitarz14/guitar-schedule) 的现有静态页面，改为极简专业工作台。无需安装依赖或构建。

## 本地运行

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765 。

## 验证

```sh
TZ=Asia/Shanghai node --test tests/*.test.*
```

测试覆盖原有学员、体验课和收入日期逻辑，以及新版概览筛选、跨午夜时长、月度分组、零时长展示、姓名转义和日期展开。

## 课程与作业反馈

直接点击课表上的课程，在「编辑课程」中填写作业总结和上课重点。上课重点为一个多行输入框，可自由记录曲目、技巧和课堂进度。点击「保存并生成分享图」，会先保存当前内容，再打开作业优先版分享预览。预览中可保存 PNG 图片，也可返回该课程继续编辑。常规课和体验课均可使用。

私人备注折叠保留，不进入分享图。已有上课记录原样带入；尚无独立记录的旧课程，会自动将曲目和技巧重点合并到上课重点中。保存、重新打开、复制和分享都使用同一份上课重点。

也可在「学员」中点击姓名或「查看」，默认显示当天的课程，并支持切换上课日期。同一天的多节课按开始时间逐节展示，已请假和取消的课程不展示。

点击「编辑记录」填写作业总结和上课重点，保存后会随课程一起进入本地存储、JSON 备份及现有云端同步。旧课程的上课重点默认取曲目和技巧重点，原有备注保持独立。

点击「生成分享图」预览作业优先版反馈图，点击「保存图片」下载 PNG，也可在手机上长按保存后发给家长。图片只包含姓名、课程类型、日期、上课时间、作业和课堂内容。

## 学员状态管理

在「学员管理」点击学员姓名，在详情的「调整状态」中选择在读、请假、停课或已结课；二次确认时可填写 200 字以内的备注。只有在读且已确认剩余课时 ≤ 2 节时显示续费提醒。停课、结课和请假保留余额及记录，恢复在读后重新判断提醒。有未来待上课程时会提示检查，不自动取消课程。

「状态历史」记录工作台操作的时间、原状态、新状态和备注，随原学员 ID 和 `stuStatus` 一起经 `teaching` 同步。旧资料或教师端未提供审计记录的操作不会补写虚构时间。发生冲突时显示两端状态，处理状态冲突保留云端最新课包；未采用的本机尝试在历史中标为「冲突未采用」。未连接、待同步、失败及冲突不会显示为已同步，冲突刷新后仍可继续处理。

本功能不修改课包流水、作业、绑定或验收，也不提供充值入口。已有学员的编辑表单不再直接切换状态，统一从详情确认并留存记录。
